# Baseline research: Yarn Spinner 3.2.2 live feature census

> Gathered during the charting session from docs.yarnspinner.dev (current = 3.2 pages), the official ANTLR grammars on YarnSpinnerTool/YarnSpinner `main`, the 3.2.2 CHANGELOG/releases, and try.yarnspinner.dev.
> Diff this against [repo-audit.md](./repo-audit.md).

## 1. Current version
- **Latest stable: v3.2.2**, changelog dated **2026-08-07**, GitHub release published 2026-08-11 (YarnSpinnerTool/YarnSpinner releases + CHANGELOG.md).
- Two release streams: **YarnSpinner** (compiler + core runtime, NuGet `YarnSpinner`/`YarnSpinner.Compiler`) and **YarnSpinner-Unity** (separate releases). Since 3.2.2 the core targets .NET Standard 2.1 only. `.yarnproject` **projectFileVersion: 4**. Yarn 3.0 shipped 16 May 2025.
- try.yarnspinner.dev is a browser SPA (wasm build); exposes saliency strategy commands `<<set_saliency first|random|best|best_least_recent|random_best_least_recent>>`.

## 2. Language features (3.2)

**Nodes/headers**: `title:` (required, letters/numbers/underscores), then any number of `key: value` headers, `---` body, `===` end. Special headers: `when:` (node groups), `tracking: always|never` (forces/suppresses visit-tracking codegen), `subtitle` (debug internal name), plus free-form/editor headers (`tags`, `position`, `colorID`, `group`, `color`, `style: note`). File-level hashtags can precede nodes.

**Lines**: optional character name = text before first `:` (implicitly becomes `[character name="X"]...[/character]` markup; `:` escapable with `\` since 3.2.0); inline expressions `{expr}`; line conditions `<<if expr>>` and `<<once>>` / `<<once if expr>>`; hashtags `#tag` (no spaces, many per line). Reserved tags: `#line:id` (unique, auto-added if missing), `#shadow:sourceLineId` (reuses another line, no string-table entry, text must match, no expressions, can't combine with `#line:`), `#lastline` (auto-added to line preceding options).

**Statements** (exact set from grammar): `line_statement`; `<<if>>/<<elseif>>/<<else>>/<<endif>>` (expressions must be boolean); `<<set $var to|= expr>>` incl. `+= -= *= /= %=`; `<<call func(...)>>`; custom commands `<<anything ...>>` with `{expr}` interpolation and trailing hashtags; `<<declare $var = value as Type>>` (optional explicit type); `<<enum Name>> <<case X>> [= rawValue] <<endenum>>`; `<<jump Node>>` or `<<jump {expr}>>`; `<<detour Node>>`/`<<detour {expr}>>` (returns on node end or `<<return>>`; a jump inside a detoured node clears the return stack); `<<return>>` (acts as `stop` if not detoured); line groups `=>`; `<<once>> [if expr] ... <<else>> ... <<endonce>>`; shortcut options `->`; indented blocks (INDENT/DEDENT).

**Not in the language**: no `<<visit>>`, no `<<unset>>` (visit state read via `visited()`/`visited_count()`; variables cannot be unset). `<<wait>>`/`<<stop>>` are built-in *commands*, not grammar keywords. No core `sfx`/`colour` commands (engine-side). No ternary operator.

**Shortcut options**: `-> line`, condition `<<if>>`, `<<once>>`/`<<once if>>`, hashtags, indented body lines and nested options; blank line ends the option group. Since 3.1: if all options are unavailable, the game may call `SetSelectedOption(Dialogue.NoOptionSelected)` and execution falls through to content after the options.

**Node groups**: multiple nodes sharing a title, each with ≥1 `when:` header (`when: <bool expr>` | `once` | `once if expr` | `always`; multiple `when:` headers = AND). Compile error if any member lacks `when:`; duplicate `subtitle` within a group is an error (YS0032).

**Smart variables**: `<<declare $x = <expression>>` — recomputed on every access, read-only (YS0030), self/cyclic reference detection (YS0045); runtime API `Dialogue.TryGetSmartVariable<T>`.

**Enums**: `<<enum>>/<<case>>/<<endenum>>`, optional uniform raw values (all-numeric or all-string; auto-numbered if none), compare only `==`/`!=` against same enum, shorthand `.Case`, usable as function params when raw type matches; `Yarn.Compiler.EnumTypeBuilder` for host-defined enums (3.2.0).

**Operators**: `eq|is|==`, `neq|!=`, `gt|>`, `lt|<`, `lte|<=`, `gte|>=`, `and|&&`, `or|||`, `xor|^`, `not|!`; `+ - * / %`; compound assignment `+= -= *= /= %=`; standard precedence (brackets, not, mul/div/mod, add/sub, comparisons, equality, and/or/xor).

**Built-in functions** (docs Functions page): `visited(node)`, `visited_count(node)`, `format_invariant(n)`, `random()`, `random_range(a,b)`, `dice(sides)`, `min`, `max`, `round`, `round_places(n,places)`, `floor`, `ceil`, `inc`, `dec`, `decimal(n)`, `int(n)`, plus conversions `string()`, `number()`, `bool()`, and `has_any_content(nodeGroup)` (3.0.2) and `format(fmt, val)`. Custom functions via `Library.RegisterFunction`, **variadic** supported (3.0).

**Markup** (generic, not a fixed tag list in core): `[tag]...[/tag]`, self-closing `[tag/]` (zero length, trims one following whitespace unless `trimwhitespace=false`), close-all `[/]`, nesting/overlap in any close order, properties (`int|float|bool|string`, shorthand `[wave=2]` ≡ `[wave wave=2]`), escaping `\[` and `\\`, `[nomarkup]...[/nomarkup]`. Built-in **replacement markers**: `[select value=… k="v" /]`, `[plural value=… one/two/few/many/other="…" /]`, `[ordinal …]` (locale-aware CLDR plural classes; `%` inserts the value). Implicit `[character name=]` marker generated before other processing (3.2.0); custom replacement processors via `IAttributeMarkerProcessor`/`BuiltInMarkupReplacer`. Styling tags like `[wave]`, `[pause]`, bold/italic, character events are **not core** — engine add-ons (Unity MarkupPalette/PauseEventProcessor etc.).

**Line groups**: `=>` items with conditions and `once`, optional indented continuation lines; selection per saliency strategy (First, Best, Best Least Recently Viewed, Random Best Least Recently Viewed — **default Random BLRV since 3.0.1**); complexity scoring: `always`=0, `once`+1, expression = boolean-operator count +1.

## 3. Compiler features
- ANTLR4 grammar (4.13.1) with indentation-aware lexer; diagnostics have **stable error codes YS0001–YS0047** (errors/warnings/info; full table on docs errors page — e.g. YS0002 type mismatch, YS0011 duplicate node title, YS0018 duplicate line ID, YS0032 duplicate subtitle in group, YS0036 feature requires newer projectFileVersion, YS0045 smart-variable cycle), each with file/line/column/context/severity. `LineParser.ParseStringAndIncludeMarkupDiagnostics` surfaces markup diagnostics (3.2.1).
- **Program format**: compiled `Program` is a **Protocol Buffers binary** (Google.Protobuf) — no user-facing `.yarnc` file; Unity embeds it in the imported Yarn Project asset. Since 3.0: jumps are instruction indices (not labels); since 3.1: `Program` carries `LanguageVersion`; `Program.Combine()` merges programs.
- **CompilationJob**: `Files`, `Declarations` (external variables/functions/enums), `Library`, `CompilationType` (FullCompilation / StringsOnly / DeclarationsOnly / type-check-only), `CancellationToken` (3.0). **CompilationResult**: `Program`, `StringTable`, `Declarations`, `Diagnostics`, `FileTags`, `ContainsImplicitStringTags`, `UserDefinedTypes` (enums).
- **Localization**: string-table entries per line with columns `language, id, text, file, node, lineNumber, lock` (first 8 hex of SHA-256 of base text), `comment`; `///` doc comments above lines become the CSV `comment`; implicit line IDs auto-generated; line tagging pluggable via `Utility.TagLines` + `ILineTagGenerator` (`RandomLineTagGenerator` default, `DescriptiveLineTagGenerator` 3.2.1). `.yarnproject` JSON: `projectFileVersion`, `sourceFiles` globs, `excludeFiles`, `baseLanguage`, `localisation` map, `definitions` (.ysls) file.

## 4. Runtime features
- **Dialogue** (implements `ISmartVariableEvaluator`): `Continue()`, `SetNode`, `SetProgram(Program)`, `SetSelectedOption(int)` (+`Dialogue.NoOptionSelected` since 3.1), `Stop()`, `UnloadAll()`, `NodeExists`, `GetHeaders`/`GetHeaderValue`, `GetStringIDForNode`, `GetTagsForNode`, `IsNodeGroup`, `GetSaliencyOptionsForNodeGroup`, `HasSalientContent`, `TryGetSmartVariable<T>`. Handlers: `LineHandler`, `OptionsHandler` (receives full `OptionSet` with `IsAvailable`), `CommandHandler`, `NodeStartHandler`, `NodeCompleteHandler`, `DialogueCompleteHandler`, `PrepareForLinesHandler` (lookahead line IDs), `LogDebugMessage`/`LogErrorMessage`. Properties: `VariableStorage` (`IVariableStorage`: `SetValue`/`TryGetValue` for bool/number(float)/string; `MemoryVariableStore` default), `Library` (function/command registration; `wait`/`stop` built-in), `ContentSaliencyStrategy` (`IContentSaliencyStrategy.QueryBestContent`/`ContentWasSelected`), `LanguageCode`, `IsActive`, `CurrentNode`, `NodeNames`.
- **VM details relevant to reimplementation**: instructions per node include saliency-candidate ops (`AddSaliencyCandidateFromNode` — 3.2.2 fixed its `Destination`); visited/visited_count tracked by the VM **on node return**, not codegen (3.0); `once` state stored as generated variables in VariableStorage (`Library.GenerateUniqueContentViewedVariableName(lineId)` / `GenerateUniqueCommandBlockViewedVariableName()`, 3.2.1 — line-ID-based, resettable); smart variables evaluated at access time; runtime line handling split out of `Dialogue` into **`LineParser`** (expands `{}` substitutions, parses markup to `MarkupParseResult` with `Attributes` (name/position/length/properties), `DeleteRange`, `TextForAttribute`); replacement markers report invisible-char counts via `ReplacementMarkerResult` (3.1). Locale-aware plural/ordinal classes at runtime.

## 5. Changelog summary
**3.0 (2025-05-16)**: enums, smart variables, `once` statements/line conditions, node groups + `when:`, `detour`/`return`, line-group saliency machinery, variadic functions, compilable cancellation, std-lib moved to core (`min`/`max`, `format`), new protobuf program format, `LineParser` takeover of markup/substitutions, `Yarn.Analysis` removed, `subtitle` header, `has_any_content` (3.0.2), default saliency → Random BLRV (3.0.1).
**3.1 (2025-12-02)**: `Dialogue.NoOptionSelected` fall-through when all options unavailable; `ReplacementMarkerResult` (invisible chars); `Program.LanguageVersion`; blank `tags:` → empty collection; visited()/visited_count() node-group fix; negative-number declarations no longer smart variables.
**3.2 (2026-03-27 → 3.2.2, 2026-08-07)**: stable error codes YS00xx; escapable `:` and implicit `[character/]` processed by marker processors (and generated first); `EnumTypeBuilder`; `ILineTagGenerator` + `DescriptiveLineTagGenerator`; `Library.GenerateUnique*ViewedVariableName`; markup-parsing diagnostics included in compilation; comments-in-headers fix; type-check-only mode emits string table; 3.2.2: type-checker fixes, negative-number lexing fix, `BestSaliencyStrategy` empty-candidates crash fix, .NET Standard 2.1-only.
